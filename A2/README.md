## Dữ liệu và cách chạy

Nguồn: https://www.kaggle.com/competitions/titanic/data
Quy tắc: https://www.kaggle.com/competitions/titanic/rules

Tải train.csv, đặt cùng notebook trong A2. Repo dùng link nguồn thay vì phát hành lại CSV. Không dùng test.csv hoặc OpenML 1309 dòng.

Dùng Python 3.10 trở lên. Tạo môi trường ảo, cài requirements.txt rồi mở notebook và Restart Kernel > Run All. Hướng dẫn đầy đủ được bổ sung cùng notebook đã chạy.
